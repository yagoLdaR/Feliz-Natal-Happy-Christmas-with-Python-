# Feliz-Natal-Happy-Christmas-with-Python-
Uma pequena animação de Natal feita com Python e Pygame, criada para compartilhar um pouco do espírito natalino com amigos e familiares.
A animação apresenta uma árvore de Natal feita de partículas, luzes, enfeites coloridos, presentes, neve e uma mensagem especial de Natal.
A ideia é que qualquer pessoa possa abrir o projeto e assistir à animação.

A small Christmas animation made with Python and Pygame, created to share a little Christmas spirit with friends and family.
The animation features a Christmas tree made of particles, lights, colorful ornaments, presents, snowfall and a special Christmas message.
The idea is for anyone to be able to open the project and enjoy the animation.



# Funcionalidades | Features
Árvore de Natal animada feita de partículas | Animated particle-based Christmas tree
Estrela no topo da árvore | Star at the top of the tree
Pisca-Pisca | Christmas lights
Enfeites coloridos | Colorful ornaments
Presentes caindo embaixo da árvore | Falling presents under the tree
Neve caindo e se acumulando no chão | Falling and accumulating snow
Mensagem animada de Natal | Animated Christmas message


# Como executar | How to run
- Português:
Instale o Python 3.
Instale o Pygame:
pip install pygame-ce
Execute o arquivo:
python christmas.py
Pressione ESC para fechar a animação.

- English
Install Python 3.
Install Pygame:
pip install pygame-ce
Run the file:
python christmas.py
Press ESC to close the animation.


# Música | Music
Para reproduzir a música da animação, coloque o arquivo christmas_music.mp3 dentro da pasta assets.
To play the animation's background music, place the christmas_music.mp3 file inside the assets folder.

O arquivo de música não está incluído neste repositório. | The music file is not included in this repository.
